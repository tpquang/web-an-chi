# Trường SEO trong CMS

Quy cách đầy đủ ở `anchi-seo/references/cms-seo.md`. CMS đặt `noindex`.

| Trường | Sản phẩm | Danh mục | Bài viết | Chủ đề |
|---|---|---|---|---|
| `slug`, tự sinh từ tên | Có | Có | Có | Có |
| `metaTitle` (đếm 45 ký tự, web tự thêm hậu tố) | Có | Có | Có | Có |
| `metaDescription` (đếm 158 ký tự) | Có | Có | Có | Có |
| `alt` của ảnh | Có | | | |
| `noindex`, `canonicalUrl`, `ogImage`, `focusKeyword` | Chưa | Chưa | Chưa | Chưa |
| Cấu hình toàn site, bảng redirect | Chưa | | | |

Sản phẩm thiếu ảnh hoặc mô tả tự `noindex` trên web, không cần trường riêng.
